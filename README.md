# Buzzting 🐝

버즈빌 동료들과 함께하는 가벼운 소개팅 플랫폼

> **Live:** https://buzzting.vercel.app

---

## 이런 분들 환영해요

- 새로운 사람 만나보고 싶은 분
- 밥 친구, 커피 친구가 필요한 분
- 그냥 심심해서 프로필 구경하고 싶은 분

## 가볍게 시작하세요

소개팅이라고 너무 어렵게 생각하지 마세요.

- 꼭 만나야 하는 건 아니에요
- 채팅만 해도 괜찮아요
- 친구로 남아도 좋아요
- 그냥 "안녕하세요" 한마디도 충분해요

**부담 없이, 가벼운 마음으로.**

---

## 기여하기

버즈빌러라면 누구나 기여할 수 있어요!

```bash
# 1. 클론
git clone https://github.com/ocean-oo/buzzting.git
cd buzzting

# 2. 의존성 설치
npm install

# 3. 환경변수 설정 (.env.local)
DATABASE_URL="your-database-url"
JWT_SECRET="your-jwt-secret"

# 4. 개발 서버 실행
npm run dev
```

http://localhost:3000 에서 확인하세요.

### Tech Stack

- Next.js 14 (App Router)
- Prisma + PostgreSQL
- Tailwind CSS
- React Query
