# Buzzting 프로젝트 개요

## 프로젝트 소개
버즈빌 직원들을 위한 사내 소개팅 앱

## 핵심 요구사항
1. **대상 사용자**: 버즈빌 직원만 사용 가능
2. **프로필 등록**: 본인 또는 본인의 친구가 등록 가능
3. **기본 기능**: 프로필 등록, 매칭 신청, 매칭 수락/거절

## 기술 스택
- **프레임워크**: Next.js 16.1.1 (App Router)
- **언어**: TypeScript
- **스타일링**: Tailwind CSS 4
- **데이터베이스**: [데이터베이스 선택 참고](./database.md)
- **인증**: [인증 시스템 참고](./authentication.md)

## 주요 기능
1. 직원 인증 및 가입
2. 프로필 등록/수정/삭제
3. 프로필 조회
4. 매칭 신청
5. 매칭 수락/거절
6. 매칭 현황 조회

## 개발 방식
- 스펙 주도 개발 (Spec-Driven Development)
- 문서 우선 작성 후 구현 진행
