# 기능 명세서

## 1. 인증

### 1.1 로그인
- **설명**: 버즈빌 직원 이메일로 로그인
- **입력**:
  - 이메일 주소 (필수, @buzzvil.com 도메인만 허용)
- **처리**:
  1. 이메일 도메인 검증
  2. 사용자 존재 확인
  3. JWT 토큰 생성 및 발급
- **출력**: 로그인 완료 및 홈 화면 이동

### 1.2 로그아웃
- **설명**: 현재 세션 종료
- **처리**: 세션 삭제
- **출력**: 로그인 화면으로 이동

---

## 2. 프로필 관리

### 2.1 프로필 등록
- **설명**: 본인 또는 친구의 소개팅 프로필 등록
- **입력**:
  - 대상 사용자 ID (본인이면 본인 ID, 친구면 친구 ID)
  - 이름 (필수)
  - 나이 (선택)
  - 자기소개 (선택)
  - 부서 (선택)
  - 관심사 (다중 선택)
  - 프로필 이미지 (선택)
  - 연락 선호 방식 (이메일/카카오/전화)
  - 연락처 정보
- **처리**:
  1. 사용자 인증 확인
  2. 대상 사용자의 활성 프로필 존재 여부 확인
  3. 프로필 생성 (registered_by = 현재 사용자 ID)
- **출력**: 프로필 생성 완료

### 2.2 프로필 수정
- **설명**: 등록된 프로필 정보 수정
- **권한**: 본인(`user_id`) 또는 등록자(`registered_by`)만 수정 가능
- **입력**: 프로필 등록과 동일 (일부 필드만 수정 가능)
- **처리**:
  1. 권한 확인
  2. 프로필 정보 업데이트
- **출력**: 수정된 프로필 정보

### 2.3 프로필 삭제 (비활성화)
- **설명**: 프로필을 비활성화 (실제 삭제 아님)
- **권한**: 본인 또는 등록자만 삭제 가능
- **처리**:
  1. 권한 확인
  2. `is_active = false`로 변경
- **출력**: 삭제 완료 메시지

### 2.4 프로필 목록 조회
- **설명**: 활성화된 모든 프로필 목록 조회
- **필터링**:
  - 부서별 필터
  - 페이지네이션
- **출력**: 프로필 카드 리스트

### 2.5 프로필 상세 조회
- **설명**: 특정 프로필의 상세 정보 조회
- **출력**: 프로필 상세 정보 (연락처 정보는 제외, 매칭 성사 후에만 공개)

## 3. 매칭 기능

### 3.1 매칭 신청
- **설명**: 다른 프로필에게 매칭 신청
- **입력**:
  - 대상 프로필 ID (필수)
  - 신청 메시지 (선택)
- **처리**:
  1. 본인 프로필 존재 확인
  2. 중복 신청 확인
  3. 본인에게 신청하는지 확인
  4. 매칭 신청 생성 (status = 'pending')
- **출력**: 신청 완료 메시지

### 3.2 매칭 신청 목록 조회
- **설명**: 보낸 신청 또는 받은 신청 목록 조회
- **필터링**:
  - 타입: `sent` (보낸 신청) / `received` (받은 신청)
  - 상태: `pending` / `accepted` / `rejected` / `cancelled`
- **출력**: 매칭 신청 리스트

### 3.3 매칭 신청 수락
- **설명**: 받은 매칭 신청을 수락
- **권한**: 신청 대상 프로필의 소유자만 수락 가능
- **처리**:
  1. 권한 확인
  2. 매칭 신청 상태를 'accepted'로 변경
  3. `matches` 테이블에 매칭 정보 생성
  4. 양쪽 프로필의 연락처 정보 공개
- **출력**: 매칭 성사 안내 및 연락처 정보

### 3.4 매칭 신청 거절
- **설명**: 받은 매칭 신청을 거절
- **권한**: 신청 대상 프로필의 소유자만 거절 가능
- **처리**:
  1. 권한 확인
  2. 매칭 신청 상태를 'rejected'로 변경
- **출력**: 거절 완료 메시지

### 3.5 매칭 신청 취소
- **설명**: 본인이 보낸 매칭 신청 취소
- **권한**: 신청자만 취소 가능
- **처리**:
  1. 권한 확인
  2. 매칭 신청 상태를 'cancelled'로 변경
- **출력**: 취소 완료 메시지

### 3.6 매칭 목록 조회
- **설명**: 성사된 매칭 목록 조회
- **출력**: 매칭 리스트 (연락처 정보 포함)

## 4. 사용자 플로우

### 플로우 1: 새 사용자 프로필 등록
1. 로그인 (이메일 입력)
2. 프로필 등록 페이지로 이동
3. 프로필 정보 입력 및 등록
4. 프로필 목록에서 본인 프로필 확인

### 플로우 2: 친구 대신 프로필 등록
1. 로그인
2. 프로필 등록 페이지로 이동
3. 친구의 사용자 ID 입력 (또는 이메일로 검색)
4. 프로필 정보 입력 및 등록

### 플로우 3: 매칭 신청 및 수락
1. 프로필 목록에서 관심 있는 프로필 선택
2. 프로필 상세 페이지 확인
3. 매칭 신청 (선택적 메시지 포함)
4. 대상자가 알림 확인 (또는 매칭 신청 목록에서 확인)
5. 대상자가 수락 또는 거절
6. 수락 시: 매칭 성사, 양쪽 연락처 정보 공개
7. 거절 시: 신청자에게 거절 알림

### 플로우 4: 프로필 수정/삭제
1. 내 프로필 페이지로 이동
2. 프로필 수정 또는 삭제
3. 변경사항 저장

---

## 5. 비즈니스 규칙

### 프로필 관련
- 한 사용자당 하나의 활성 프로필만 허용
- 본인 또는 친구가 대신 등록한 프로필은 본인 또는 등록자가 수정/삭제 가능
- 프로필 삭제 시 실제로 삭제하지 않고 `is_active = false`로 변경 (데이터 보존)

### 매칭 관련
- 같은 두 프로필 간 중복 신청 불가
- 본인 프로필에 신청 불가
- 매칭 신청 수락 시에만 연락처 정보 공개
- 매칭 신청은 신청자와 대상자만 취소/거절 가능

### 권한 관련
- 인증된 사용자만 프로필 등록/조회 가능
- 프로필 수정/삭제는 본인 또는 등록자만 가능
- 매칭 신청 수락/거절은 대상 프로필 소유자만 가능

- 이메일 알림 기능

- 매칭 통계 및 분석

- 관리자 페이지 (프로필 관리, 사용자 관리)
- 다국어 지원
