# 인증 시스템

## 개요
사내 직원만 사용 가능한 서비스. 직원 정보는 미리 DB에 등록되어 있음.
외부 게스트도 조회는 가능하나 매칭 신청은 불가.

## 인증 방식

### 1. 직원 로그인
- `@buzzvil.com` 도메인 이메일만 허용
- 이메일 입력만으로 로그인 (비밀번호 없음)
- DB에 등록된 사용자만 로그인 가능
- JWT 토큰 7일 유효

### 2. 게스트 로그인
- 버튼 클릭으로 즉시 로그인 (별도 입력 없음)
- DB에 저장되지 않음 (JWT 토큰으로만 처리)
- JWT 토큰 1일 유효
- 프로필 조회만 가능, 매칭 신청 불가

## 로그인 흐름

### 직원
1. 이메일 입력
2. `@buzzvil.com` 도메인 검증
3. DB에서 사용자 조회
4. JWT 토큰 발급
5. 클라이언트에서 localStorage에 토큰 저장

### 게스트
1. "버즈빌 직원의 친구인가요?" 버튼 클릭
2. JWT 토큰 발급 (isGuest: true)
3. 클라이언트에서 localStorage에 토큰 저장

## 세션 관리
- JWT 토큰 기반
- Authorization: Bearer {token} 헤더로 인증

## 권한 관리
| 권한 | 직원 | 게스트 |
|------|------|--------|
| 프로필 목록 조회 | O | O |
| 프로필 상세 조회 | O | O |
| 매칭 신청 | O | X |
| 매칭 수락/거절 | O | X |
| 프로필 등록/수정 | O | X |
