# 인증/인가 시스템 스펙

## 개요
버즈빌 직원만 사용할 수 있는 서비스이므로, 직원 인증이 필수입니다.

## 직원 인증 방법 제안

### 옵션 1: 이메일 도메인 기반 인증 (추천 - 간단)
**방식**: 
- 회원가입 시 `@buzzvil.com` 도메인 이메일만 허용
- 이메일 인증 코드 발송 후 인증 완료

**장점**:
- 구현이 간단함
- 추가 인프라 불필요
- 빠르게 적용 가능

**단점**:
- 이메일 도메인만으로는 완벽한 검증은 어려움 (도메인 스푸핑 가능성)

**구현 방식**:
1. 회원가입 페이지에서 이메일 입력
2. `@buzzvil.com` 도메인 검증
3. 이메일 인증 코드 발송 (Nodemailer 또는 Resend 사용)
4. 인증 코드 입력 및 검증
5. 회원가입 완료

---

### 옵션 2: OAuth + 이메일 도메인 화이트리스트
**방식**:
- Google OAuth 로그인
- 추가로 이메일 도메인이 `@buzzvil.com`인지 검증

**장점**:
- Google 계정으로 간편 로그인
- 이메일 인증 코드 발송 로직 불필요

**단점**:
- OAuth 구현 필요
- Google 계정이 없는 경우 대응 필요

**구현 방식**:
1. NextAuth.js 또는 Auth.js 사용
2. Google Provider 설정
3. 콜백에서 이메일 도메인 검증
4. `@buzzvil.com` 도메인만 허용

---

### 옵션 3: 사내 인증 시스템 연동 (장기적)
**방식**:
- 버즈빌 내부 인증 시스템(SSO, LDAP 등)과 연동

**장점**:
- 가장 안전한 인증 방식
- 기존 직원 시스템과 통합

**단점**:
- 내부 시스템 접근 권한 필요
- 구현 복잡도 높음
- 초기 개발 단계에서는 비현실적

---

## 추천 방안
**초기 버전**: 옵션 1 (이메일 도메인 + 인증 코드)
- 빠르게 구현 가능
- 충분한 수준의 보안
- MVP 개발에 적합

**향후 개선**: 옵션 2 (OAuth) 또는 옵션 3 (사내 시스템 연동)
- 사용자 편의성 향상
- 더 강력한 인증

## 세션 관리
- JWT 또는 NextAuth.js 세션 사용
- 쿠키 기반 세션 관리

## 권한 관리
- **일반 사용자**: 프로필 등록, 조회, 매칭 신청/수락
- **본인 프로필 관리**: 본인의 프로필은 본인만 수정/삭제 가능
- **친구 대신 등록**: 친구 대신 등록한 경우, 친구 인증 필요 (추가 검토 필요)
